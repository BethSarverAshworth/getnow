Module 1 · College mathematics

Math you actually need for IT and certs

College math for this path is not calculus first. It is algebra, units, binary, hex, logic, powers of two, and a little probability. That is the math on Network+ and Security+.

Open the math symbols and terminology chart if a sign or word is new. Use the calculator for formulas, binary, and subnet size.

1. Order of operations and formulas

Use PEMDAS: Parentheses, Exponents, Multiply/Divide (left to right), Add/Subtract (left to right).

2 + 3 × 4 = 14    not 20
(2 + 3) × 4 = 20

IT formulas are the same idea. Example: usable hosts in a subnet:

usable hosts = 2^(32 − prefix) − 2

For a /24: 32 − 24 = 8, 2^8 = 256, minus 2 (network + broadcast) = 254 hosts.

Practice. What is 5 + 12 ÷ 4 × 2?
Divide and multiply left to right: 12 ÷ 4 = 3, 3 × 2 = 6, then 5 + 6 = 11.

2. Percent, ratios, and “how much is left”

Percent means “per 100.” 25% = 0.25. Disk and bandwidth questions use this constantly.

used = 40 GB of 160 GB
percent used = 40 / 160 = 0.25 = 25%

A ratio 1:4 means one part to four parts (5 parts total). If a RAID or staff split is 1:4 of 100 tickets, first person gets 20, second gets 80.

Practice. A 1 Gbps link is 70% used. How much is free, in Mbps?
1 Gbps = 1000 Mbps. 70% used = 700 Mbps used. Free = 300 Mbps (30%).

3. Bits, bytes, and speed units

Computers count in powers of two. Networking speeds are usually decimal (1000).

UnitEqualsRemember
bit (b)0 or 1lowercase b
byte (B)8 bitsuppercase B
Kbps / Mbps / Gbpsspeednetwork links
KB / MB / GBsizefiles and disks

A 100 Mbps download is not 100 MB per second. 100 Mbps ÷ 8 = 12.5 MB/s in a perfect world.

Practice. How many bits in 2 KB? (use 1 KB = 1024 bytes)
2 × 1024 bytes = 2048 bytes × 8 = 16,384 bits.

4. Algebra: solve for the missing piece

Whatever you do to one side, do to the other.

3x + 7 = 22
3x = 15
x = 5

Bandwidth example: time = size / speed. If a 400 MB file moves at 50 MB/s, time = 400/50 = 8 seconds.

Practice. 4x − 9 = 23. Find x.
4x = 32, x = 8.

5. Binary and hex (this is exam math)

Decimal is base 10. Binary is base 2. Hex is base 16 (0–9 then A–F).

DecimalBinaryHex
000000
101010A

2551111 1111FF

Powers of two you should memorize: 1, 2, 4, 8, 16, 32, 64, 128, 256, 512, 1024.

Convert 13 to binary: 8+4+1 = 1101.

IPv4 addresses are four decimal octets 0–255. MAC addresses are hex (example 00:1A:2B:3C:4D:5E).

Practice. Convert binary 1100 0000 to decimal.
128+64 = 192. That is why 192.168.x.x starts with 192 (11000000).

6. Boolean logic

Firewalls and access control use Boolean logic.

OpMeaningExample

1 AND 1 = 1
1 AND 0 = 0
1 OR 0  = 1
NOT 1   = 0
Practice. True AND False OR True. If AND happens first: what is the result?
True AND False = False. False OR True = True.

7. Subnet math (Network+ core)

An IPv4 address has 32 bits. The prefix (like /24) is how many bits identify the network.

PrefixMaskHost bitsAddressesUsable hosts
/24255.255.255.08256254
/25255.255.255.1287128126
/26255.255.255.19266462
/30255.255.255.252242 (point-to-point)

Rule: host bits = 32 − prefix. Total addresses = 2^(host bits). Usable = that minus 2 (except some /31 special cases you can ignore for now).

Practice. How many usable hosts on a /27?
32 − 27 = 5 host bits. 2^5 = 32. 32 − 2 = 30 usable hosts.

8. Probability and risk (Security+ language)

Risk is roughly likelihood × impact. If a phishing click is “likely” and the impact is “steal all mail,” risk is high even if the tech is simple.

If a 4-digit PIN is random, there are 10,000 possibilities (0000–9999). One guess has probability 1/10000.

Practice. A coin is fair. Probability of heads twice in a row?
1/2 × 1/2 = 1/4 (25%). Independent events multiply.

Checkpoint

You are ready for Network+ math when you can: convert 192 to binary, size a /24 and /26, and explain bits vs bytes. Do this module again if any of those are shaky.
