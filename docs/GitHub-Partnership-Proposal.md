## 1. Executive summary

GetNow is a free, career-focused IT learning and collaboration platform. We help students, career changers, and early-career tech professionals build real skills—and we already include a path for learners to publish work to GitHub.

We are seeking a partnership with GitHub to expand free access for learners, align with GitHub Education / Campus / Student Developer Pack programs, and give GitHub a high-intent channel of future developers, sysadmins, and security practitioners who form habits around Git, repos, and open collaboration early.

---

## 2. The problem we solve

Many people enter IT through helpdesk, networking, Linux, and security paths—not only software engineering bootcamps. They need:

- Structured, searchable resources (not random YouTube tabs)
- Hands-on tools (labs, network checks, documentation)
- Safe collaboration (team rooms, shared scripts, live discussion)
- A bridge into **professional version control and portfolios on GitHub**

GetNow unifies those needs in one free product, with optional Pro learning packs.

## 4. Why partner with GitHub

### Alignment with GitHub’s mission
GitHub thrives when more people learn to collaborate with code, docs, and open workflows. GetNow’s audience is upstream of that journey: learners documenting labs, sharing scripts, and needing a home for portfolios.

### Audience GitHub cares about
- Students and career switchers in IT / cybersecurity / cloud
- Community college and certificate programs (A+, Network+, Security+, Linux, cloud fundamentals)
- Helpdesk and junior admin tracks building first GitHub portfolios

### Natural product fit
- Encourage **GitHub-hosted lab notes and script vaults**
- Guide users into **Student Developer Pack** and Education benefits
- Use **GitHub Classroom / Campus** patterns for instructors who assign GetNow + repo deliverables
- Surface **good first issues / open-source contribution paths** for IT-relevant projects

## 5. Proposed partnership models

We are open to one or more of the following:

### A) GitHub Education / Campus affiliation
- List GetNow as a recommended free resource for IT / infrastructure / security learners  
- Co-branded landing page: “GetNow for GitHub Students”  
- Instructor guides: assign GetNow modules + student repo submissions  

### B) Student Developer Pack inclusion (or featured companion tool)
- Offer free or extended GetNow Pro access to verified students  
- In-app callouts for GitHub Student benefits and Codespaces  

### C) Integration partnership
- Deeper, first-class **“Save to GitHub”** (OAuth App instead of personal tokens)  
- Optional template repositories for lab write-ups, incident journals, and network diagrams  
- “Publish learning path progress” as commits or GitHub Discussions  

### D) Content / community collaboration
- Joint webinars or Campus expert sessions (networking, Linux, security fundamentals)  
- GitHub blog or Education newsletter feature on IT pathways into open source  

### E) Sponsorship / mutual growth (if appropriate)
- Modest sponsorship to keep GetNow free at scale  
- GitHub branding in Pro and Education tiers in exchange for Pack benefits for our users  

We can start small (Education listing + OAuth Save-to-GitHub) and expand based on results.
