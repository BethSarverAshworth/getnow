Ping cheat panel

          
True ICMP ping from your terminal:

          
# macOS / Linux
ping -c 4 TARGET

# Continuous
ping TARGET

# Windows
ping -n 4 TARGET

# Traceroute
traceroute TARGET      # Mac/Linux
tracert TARGET         # Windows

# PowerShell
Test-NetConnection TARGET -InformationLevel Detailed
Test-Connection TARGET -Count 4
